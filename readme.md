📋 WWC抽卡系统 完整指令说明
==========================================
改用官方puppeteer
### 一、基础功能
1. **注册**：首次使用必须注册
   - 指令：WWC注册 [昵称]
   - 示例：WWC注册 风之旅行者
   - 说明：注册后可参与抽卡、签到、兑换等所有功能

2. **签到**：每日领取抽数
   - 指令：WWC签到
   - 示例：WWC签到
   - 说明：每日可签到1次，获得40抽，重置时间由管理员配置

3. **仓库**：查看已拥有的卡片（含等级/星级）
   - 指令：WWC仓库
   - 示例：WWC仓库
   - 说明：卡片按星级降序排列，显示等级和编号

4. **收藏**：查看卡片收藏进度
   - 指令：WWC收藏 / WWC收藏1 / WWC收藏2 / WWC收藏3
   - 示例：WWC收藏
   - 说明：生成收藏进度图片。WWC收藏为完整图鉴；收藏1/2/3为拆分版，避免图片过长过大，分类规则由配置项 `collectionPart1Pattern` / `collectionPart2Pattern` 以正则定义（收藏3 = 不匹配前两者的剩余类别）

5. **排名**：查看全服收藏排行
   - 指令：WWC排名1 / WWC排行1
   - 示例：WWC排名1
   - 说明：显示前20名玩家，同时展示自己的排名和收藏数

6. **排名2**：查看全服高星战力排行
   - 指令：WWC排名2 / WWC排行2
   - 示例：WWC排名2
   - 说明：按已拥有卡片累计战力分排序，7星 0级20分、每级+15；普通6星 0级5分、每级+3；限时6星 0级8分、每级+6

### 二、抽卡功能
1. **普通抽卡**：消耗普通抽数抽卡
   - 指令：WWC抽卡 [次数]（1-20连）
   - 示例：WWC抽卡 10（10连抽）
   - 说明：单次最多20连，6/7星高星卡会单独播报
   - 保底阈值由配置项 normalStar7Threshold / normalStar6Threshold 控制（管理员可调）

2. **限时抽卡**：参与UP卡池抽卡（普通卡池+限时UP卡）
   - 指令1：WWC限时抽卡 [期数] [次数]（多卡池开放时）
   - 指令2：WWC限时抽卡 [次数]（单卡池开放时）
   - 示例1：WWC限时抽卡 2601 20（2601期20连）
   - 示例2：WWC限时抽卡 5（单卡池5连）
   - 说明：需先兑换限时抽数，6/7星UP概率不同。累计抽数达到保底时必定获得当期UP卡，每期仅发1张
   - 保底阈值（配置项 eventStar6Threshold / eventStar7Threshold，可由管理员调整）：
     - 默认：6星 200 抽 / 7星 400 抽

3. **扰动抽卡**：用热带扰动抽卡（仅普通卡池5/6/7星）
   - 指令：WWC扰动抽卡 [次数]（1-20连）
   - 示例：WWC扰动抽卡 10
   - 说明：每抽概率 7星10% / 6星36% / 5星54%，抽中卡片正常计入仓库并升格，**不做高星播报**，不影响普通抽卡的抽数与保底

4. **扰动兑换**：用热带扰动兑换扰动抽数
   - 指令：WWC扰动兑换 [次数]（1-40抽）
   - 示例：WWC扰动兑换 20
   - 说明：默认 100 扰动 = 1抽（配置项 `disturbExchangePrice`），无每日上限

### 三、兑换/升格功能
1. **普通兑换**：用水汽兑换普通抽数
   - 指令：WWC兑换 [次数]（1-40抽）
   - 示例：WWC兑换 30（兑换30抽）
   - 说明：100水汽=1抽，每日上限80抽

2. **限时兑换**：用水汽兑换限时抽数
   - 指令：WWC限时兑换 [期数] [次数]（1-40抽）
   - 示例：WWC限时兑换 2601 15（2601期兑换15抽）
   - 说明：6星限时卡300水汽/抽，7星450水汽/抽

3. **店铺升格**：用热带扰动兑换指定卡片
   - 指令：WWC升格 [卡片编号]（可多个编号）
   - 示例：WWC升格 2660 1513（兑换编号2660和1513的卡片）
   - 说明：每日店铺卡片随机刷新，有全服兑换上限

4. **店铺**：查看今日可升格的卡片
   - 指令：WWC店铺
   - 示例：WWC店铺
   - 说明：每日随机刷新 4 个7星 + 6 个6星 + 10 个5星（均来自普通卡池），全服每卡每日限购 5 次。价格为 7星 800±80、6星 200±30、5星固定 20 扰动。图片中每行显示**当日全服剩余可购次数**，抽卡与升格结果均显示剩余抽数

### 四、管理员功能（仅主人可用）
1. **卡片录入**：添加新卡片到卡池
   - 指令：WWC录入（换行后输入卡片信息）
   - 示例：
     WWC录入
     2660 春樱吹 6 2026限定
     1513 苏迪罗 7 台风
   - 说明：每行1张卡，格式：卡片ID 名称 星级 类别

2. **审核昵称**：通过用户的昵称注册申请
   - 指令：WWC审核 [用户QQ]
   - 示例：WWC审核 123456789
   - 说明：审核后用户可显示自定义昵称，否则显示QQ号

3. **驳回昵称**：驳回用户的昵称申请或修改，恢复原昵称/显示QQ号
   - 指令：WWC驳回 [用户QQ]
   - 示例：WWC驳回 123456789
   - 说明：已通过的用户会恢复其原昵称；未通过的用户将显示为QQ号

4. **限时卡池录入**：添加限时UP卡池
   - 指令：WWC限时录入 [期数] [卡片ID] [名称] [星级] [类别] [开始时间戳] [结束时间戳]
   - 示例：WWC限时录入 2601 2660 春樱吹 6 2026 1775088000000 1775951999000
   - 说明：时间戳需为北京时间（UTC+8）的毫秒数

5. **功能开关**：控制全局/群聊功能开关
   - 指令1：WWC开启全部（全局开启所有功能）
   - 指令2：WWC关闭全部（全局关闭所有功能）
   - 指令3：WWC开启（当前群开启功能）
   - 指令4：WWC关闭（当前群关闭功能）
   - 示例：WWC开启全部

6. **全群广播**：向所有开启功能的群发送消息
   - 指令：WWC广播 [消息内容]
   - 示例：WWC广播 限时卡池「春樱吹」已开放，6星UP概率25%！
   - 说明：仅主人可使用，避免骚扰群聊

### 五、查询功能
1. **限时卡池状态**：查看当前开放的限时卡池
   - 指令：WWC限时状态
   - 示例：WWC限时状态
   - 说明：显示期数、卡片名称、星级、开放时间

2. **帮助指令**：查看本说明
   - 指令：WWChelp
   - 示例：WWChelp
   - 说明：随时调用，查看所有指令用法
